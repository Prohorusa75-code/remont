# Чистовик — сайт ремонта квартир под ключ для портфолио

Вымышленная компания. Стиль «чертёж»: бумага с сеткой, графит, синие линии, оранжевые кнопки.

Next.js 16 (App Router) + TypeScript + Tailwind 4, статический экспорт без бэкенда.

## Команды

```bash
npm install
npm run dev      # разработка: http://localhost:3000
npm run build    # статическая сборка в папку out/
```

Публикация — GitHub Actions (`.github/workflows/pages.yml`) собирает сайт с подпапкой `/remont`
и выкладывает на GitHub Pages при каждом пуше в `main`.

## Где что

- `src/app/page.tsx` — страница: первый экран, виды ремонта, калькулятор, этапы, объекты, гарантии, вопросы, заявка.
- `src/lib/data.ts` — цены за м² (BYN), сроки, этапы, объекты, вопросы.
- `src/components/BeforeAfter.tsx` — слайдер «до/после» с нарисованной комнатой.
- `src/components/Estimate.tsx` — калькулятор сметы и заявка на замер (общее состояние, телефон +375).
- `src/components/Steps.tsx` — этапы с линией, которая заполняется при прокрутке.
